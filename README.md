# Thiranex Internship – Task 1
## HTML5 Semantic Structure & Accessibility

A multi-page personal portfolio demonstrating semantic HTML5, WCAG-friendly accessibility practices, SEO metadata and a keyboard-accessible contact form.

### Pages
- `index.html` – Home
- `about.html` – About
- `projects.html` – Projects
- `contact.html` – Contact

### Accessibility features
- Semantic `header`, `nav`, `main`, `section`, `article` and `footer`
- Skip-to-content link
- Keyboard-visible focus states
- Descriptive navigation labels
- Proper form labels and required states
- Accessible `aria-current`, `aria-label` and `aria-describedby`
- Responsive layout
- Reduced-motion support
- Sufficiently contrasting text and controls

### SEO features
- Unique page titles
- Unique meta descriptions
- Viewport metadata
- Robots metadata
- Canonical URLs
- Descriptive headings and semantic document structure

### How to run
Open `index.html` in a browser, or use VS Code Live Server.
